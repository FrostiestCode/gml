Getting started

Build the solution, deploy the proxy into Just Cause 3, and confirm that the signature database resolved your exe. If it did, the console and spawn menu work; if it did not, GML will tell you instead of crashing.

What you need

  • Windows 10 or 11, x64. The loader and every mod are 64-bit.
  • Just Cause 3 on Steam (app 225540). GML has been verified against the retail exe with SizeOfImage 0x3241000 and TimeDateStamp 0x5787641C.
  • Visual Studio 2026 with Desktop development with C++ and the v145 platform toolset, as used by this repository. Another toolset can work if you retarget the projects.
  • PowerShell 5.1+ for the deploy script.
  • The game must be closed while you deploy; Windows locks loaded DLLs.

One build, on purpose. Signatures are keyed to the exe fingerprint. On a different build they stay unresolved and dependent features return GML_ERR_NOT_RESOLVED. There is no supported "just try the old addresses" mode, because that is how mods crash other people's games.

1. Build

From the repository root, build the solution in Release / x64:

& "C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\MSBuild.exe" `
    GrappleModLoader.sln /p:Configuration=Release /p:Platform=x64 `
    /m /v:minimal /nologo

If msbuild is already on your PATH, the short form works too: 

msbuild GrappleModLoader.sln /p:Configuration=Release /p:Platform=x64 /m

The build writes the proxy, the core DLL and the sample mods under dist\Release\. If that folder is missing when you deploy, the build did not finish.

2. Deploy

The deploy script locates your Steam library, backs up anything it is about to overwrite, and mirrors the build into the game folder: 

.\tools\Deploy.ps1 -Configuration Release

If it cannot find the game, point it at the folder that contains JustCause3.exe:

.\tools\Deploy.ps1 -GamePath "D:\Games\SteamLibrary\steamapps\common\Just Cause 3"

What ends up in the game folder:

Just Cause 3\ ├─ dinput8.dll GML.Loader — the proxy the game imports ├─ GrappleModLoader.dll GML.Core — the framework └─ GrappleModLoader\ ├─ config.json created on first run ├─ signatures.json created on first run ├─ logs\ │ └─ crashes\ └─ mods\ ├─ ExampleMod\ ├─ PlayerTeleportMod\ ├─ BorderlessMod\ └─ SigHunter\

dinput8.dll is the only file the game loads directly. It forwards DirectInput8Create to the real system DLL, then loads GrappleModLoader.dll. Keep the loader boring — it is the one component that cannot fail loudly.

3. Launch and verify

Start Just Cause 3 normally through Steam

No special launcher or command line is required.

Press ` to open the console

A transparent overlay should appear with a scrollback area and an input line. An external Win32 console opens too unless you disabled it.

Check the build

Run gml.game to see the exe fingerprint. gml.diag prints modules, hooks and subscriptions; gml.sig reports the signature inventory.

Try the verified features

gml.player reports the player chain, tp.set x y z moves Rico, and Numpad 0 opens the spawn menu.

Toggle borderless

F11 switches the window mode and restores the exact previous style on the way back.

Install a mod

A mod is a folder under GrappleModLoader\mods\ containing a mod.json and the DLL it names:

<game>\GrappleModLoader\mods\MyMod\ ├─ mod.json └─ MyMod.dll

Then reload from the console:

gml.mods
gml.mod reload

During development you cannot overwrite a DLL the game has loaded. Rename the loaded file to *.old.dll, copy the new build in, run gml.mod reload, then delete the old file. Full details and the lifetime rules are in Mod format.

Controls and config

The short version: ` console, Numpad 0 spawn menu, F11 borderless. While a panel is open the game receives no gameplay input — DirectInput reads are neutralised and the cursor is frozen.

GrappleModLoader\config.json is created on first run. It covers log level, the external console, crash handling, console opacity, spawn-menu keys and the borderless hotkey. The full table is on the features page. Inspect the loaded values with gml.config.

Troubleshooting

Nothing happens on launch

  • Confirm both dinput8.dll and GrappleModLoader.dll are next to JustCause3.exe, not inside GrappleModLoader\.
  • Check that the deploy script did not report a missing build output.
  • Read GrappleModLoader\logs\grapplemodloader.log. The loader logs its boot order and the first failure.

Features return GML_ERR_NOT_RESOLVED

  • Your exe is probably a different build. gml.game shows the fingerprint GML sees.
  • The log names the signature entry that failed to resolve. That is the honest result, not a bug.
  • Do not paste addresses from another build into signatures.json. Each entry needs a pattern and a runtime proof on your exe — see Signatures & research.

The console opens but the game still moves

  • Make sure the panel is actually open; the input gate follows the panel state.
  • If you rebound console.toggleKey, the old key no longer toggles it.
  • Report it with gml.diag output and the log; that is the evidence needed to fix a gate.

The game crashed

  • Look in GrappleModLoader\logs\crashes\ for a minidump and report.
  • Set loader.logLevel to debug or trace before reproducing.
  • gml.crash and the debug API can write a dump on demand; useful before a long session.

Uninstall

.\tools\Deploy.ps1 -Uninstall

This restores the backups and removes GML. Your mods folder and config.json are kept. Add -PurgeData to delete GrappleModLoader\ entirely (it asks first; -Force skips the prompt).
