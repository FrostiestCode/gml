Read the loader.

Start here if you just want it running. The getting started guide takes you from a clean checkout to a working console and spawn menu, and tells you what to check when a signature does not resolve.

Quick start

Build the whole solution, then let the deploy script place it in Just Cause 3:

# build (VS 2026, platform toolset v145, x64)
msbuild GrappleModLoader.sln /p:Configuration=Release /p:Platform=x64 /m

# install into the game folder (backs up the previous dinput8.dll)
.\tools\Deploy.ps1 -Configuration Release

Launch the game, press ` for the console and Numpad 0 for the spawn menu. Full detail, including the exact Visual Studio path, is in Getting started.

Source and provenance

The site summarises the public repository. The full reverse-engineering write-ups, signature patterns and original recon notes live there:

  • ARCHITECTURE.md — module layout and internals.
  • MOD_FORMAT.md — the authoritative mod contract.
  • SIGNATURES.md — schema, inventory and research rules.
  • RE_PLAYER_CHAIN.md — player chain, teleport, spawn and harvest evidence.
  • JC3_API_REFERENCE.md — the jc3-api provenance and build-mismatch proof.
  • ROADMAP.md — the live status list.

Third-party research is credited: jc3-api (MIT, © 2016 Alexander Guettler) supplied hash tables and the API blueprint; jc3-console-thingy (MIT, © aaronkirkham) was cross-checked for the model-harvest mechanism. No game addresses from either project are trusted as-is.
