Mod format

A GML mod is a 64-bit DLL described by a mod.json and loaded through a pure C ABI. Four working mods in the repository are the reference implementation for everything on this page.

mod.json

{
  "id": "com.grapple.example",
  "name": "Grapple Example Mod",
  "version": "1.0.0",
  "priority": 0,
  "entry": "ExampleMod.dll",
  "requires": [
    { "id": "com.grapple.other", "version": "1.0.0" }
  ]
}
FieldRequiredMeaning
idYesUnique, stable, reverse-DNS-ish identifier. Use the same string as the owner for subscriptions, hooks and commands.
nameYesHuman-readable name shown by gml.mods.
versionYesMod version. Compared against requires entries and passed to GML_ModInit.
priorityNoLoad order; lower loads first. Defaults to 0. Unload happens in reverse.
entryYesThe DLL inside the mod folder. Keep it next to mod.json.
requiresNoOptional dependency list. An unresolved dependency is a load failure, not a warning.

The entry point

Export exactly two C functions; the shutdown export is optional:

#include <gml/GML_Mod.h>

static int OnInit(const GML_ModContext* ctx)
{
    // ctx->api          never null when GML called you
    // ctx->modId        your id; use it as the owner for everything
    // ctx->modDirectory absolute path to this mod's folder
    return GML_OK;        // anything else = load failure, DLL is unloaded
}

static void OnShutdown()
{
    // Stop threads first. GML removes forgotten hooks, subscriptions
    // and commands by owner, but cannot save a live thread in a freed DLL.
}

GML_MOD_ENTRY2(OnInit, OnShutdown)

GML_MOD_ENTRY2 emits both exports and stores the API pointer for the C++ helpers in gml::. If you need the raw exports instead, the signatures are int GML_ModInit(const GML_ModContext*) and void GML_ModShutdown(void).

ABI rules

  1. C, not C++. No STL, classes or exceptions across the boundary. Every struct starts with a uint32_t size; GML never reads past the size you compiled against, and you must do the same for structs you receive.
  2. Versioned pointers. GML_Api holds sub-struct pointers (core, console, event, memory, player, prop, …). Null-check anything you did not verify at compile time. New sub-APIs are appended; old loaders leave them NULL.
  3. Whoever allocated, frees. GML frees nothing a mod allocated, and vice versa. Use core->Alloc / Free for anything that crosses the module boundary.
  4. Owner = your mod id. Subscribe, hook and register commands with ctx->modId. GML removes everything owned by that id on unload. A literal owner string leaks the listener across reloads and faults every tick afterwards.
  5. No blocking in GML_ModInit. It runs on the loader's thread during boot. Spawn a worker for long work and join it in shutdown.
  6. SEH is not yours to use. GML wraps every call into mod code with its own handler. Do not add __try to mod code; it changes how your frames unwind.
  7. Static CRT. Mods link /MT (or /MTd). Each mod owns its heap privately, which is what makes rule 3 simple.

Events

uint64_t sub = api->event->Subscribe(
    api->events->Tick, OnTick, nullptr, 0, ctx->modId);

api->event->Unsubscribe(sub);   // in shutdown; GML also cleans up by owner
EventPayload / notes
gml.tickGML_TickEvent: delta seconds, uptime, frame. GML's own timer — no game hook needed.
gml.presentGML_PresentEvent: swapchain, device, context. Render thread — never block or resize windows here.
gml.mod.loadedGML_ModEvent: id, name, version.
gml.mod.unloadingGML_ModEvent: last chance to clean up.
gml.config.reloadedGML_ConfigEvent: source of the reload.
gml.console.commandGML_ConsoleEvent: raw typed line.
gml.console.toggledGML_ConsoleToggleEvent: visible flag.
gml.game.readyGML_GameReadyEvent: signatures resolved and the game loop hook, if any, is installed.
gml.game.shutdownGame shutdown notification.
gml.player.spawnNeeds research to fire reliably.
gml.entity.destroyedNeeds research.
gml.world.streaminNeeds research.
gml.lua.reloadedReserved for GrappleLua.

Subscriptions take a priority; lower runs first. Dispatch copies the listener list and calls handlers outside the mutex, so a handler may emit another event. The DispatchGate is what makes unloading safe while the render thread is inside a listener.

Console commands

api->console->RegisterCommand(
    "mymod.do", "One line of help", "mymod.do <arg>",
    &OnCommand, ctx->modId);

api->console->UnregisterCommand("mymod.do");   // in shutdown

Output goes through GML_CommandOutputFn, so it lands in the overlay scrollback, the external console and the file log at once. Parse arguments defensively — the console is typed by humans.

Game APIs

Everything gameplay-facing lives behind versioned sub-structs and degrades to GML_ERR_NOT_RESOLVED when its signature is not live: 

GML_Vec3 pos{};
if (api->player->GetPosition(&pos) != GML_OK) {
    // say so; do not guess an address
}

api->player->SetPosition(&pos);   // verified: moves Rico and it sticks

void* handle = api->prop->Spawn(
    "v0008_car_autostraad_modernsportssaloon_civilian_01", &pos);
// Spawn is async; prop.status lists handles.

The callable surface and the verified / unresolved split are on the C++ API page.

Hot reload

gml.mod reload (or enable/disable followed by reload) performs three steps:

  1. The tick thread is quiesced. The DispatchGate blocks new dispatch until every in-flight Present and console callback has returned.
  2. Mods unload in reverse priority order: GML_ModShutdown under SEH, then hooks, subscriptions and commands by owner, then FreeLibrary.
  3. The mods folder is re-discovered and loaded again; gml.mods shows the result.

Replacing a loaded DLL. Windows will not let you overwrite it. Rename the old file to *.old.dll, copy the new build in, run gml.mod reload, then delete the old file. Also note that gml.mod disable currently marks a mod but a reload still loads enabled folders; the rename route is the reliable one while iterating.

Build and deploy a mod

Add a plain .vcxproj to GrappleModLoader.sln, link /MT, and have the post-build step stage mod.json next to the DLL. tools\Deploy.ps1 mirrors every folder under dist\<cfg>\mods\* into the game, so a new mod in the same shape deploys for free.

<game>\GrappleModLoader\ config.json, signatures.json, logs\ mods\<ModName>\ mod.json <ModName>.dll (+ anything else the mod wants)
