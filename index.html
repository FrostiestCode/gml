01 / RUNTIME

Native mod loading

A lightweight dinput8.dll proxy boots a C++ core, loads 64-bit mod DLLs against a stable C ABI, and hot-reloads them without restarting the game.

MOD FORMAT →
02 / GAME ACCESS

Signatures, not guesses

Every game address resolves from a build-keyed signature database and byte-verifies at load. Unknown builds get an honest error instead of a crash.

A teleport that sticks.

Developer access, in game.

Transparent overlay console with scrollback and an optional external Win32 console. While a panel is open, gameplay input is fully gated.

MODS // HOT RELOAD

Reload without a restart.

gml.mod reload unloads a mod safely through the DispatchGate, so its hooks, events and commands go away cleanly before the new DLL loads.
